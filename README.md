1. buka website https://luaobfuscator.com/forum/

2. login menggunakan akun anda, biasanya discord

3. Pencet "Api key" atau "Keys" lalu buat api key baru

3. Enter lalu tunggu proses nya hingga selesai

4. selesai, hasilnya bakal ada di folder yang sama dengan file Obfuscator.exe.

This project is open source.

How to generate an API key:

1. Visit https://luaobfuscator.com/forum/

2. Log in using your account (usually Discord).

3. Click "API key" or "Keys" and create a new API key.

4. Copy the API key, open the "Obfuscator.exe" application, enter your API key, and you're all set.

How to use the application:

1. Enter your API key.

2. Point to the location of your .lua file (e.g., D:/scriptlua/test.lua).

3. Press Enter and wait for the process to complete.

4. Done; the result will be located in the same folder as the Obfuscator.exe file.
